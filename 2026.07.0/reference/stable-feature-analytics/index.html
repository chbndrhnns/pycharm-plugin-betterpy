Feature Analytics¶

This table lists the low-cardinality feature_used metrics currently implemented through FeatureAnalytics.FeatureId. Some instrumented features are dev-only and are intentionally not listed in src/main/resources/feature-sets/stable.yaml; stable coverage checks only require stable features to have analytics, not the reverse. Each feature owns its action enum by implementing FeatureAnalytics.FeatureAction.
