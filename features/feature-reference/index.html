BetterPy Feature Reference¶

This document lists all features available in the BetterPy plugin.

Summary¶

Status Count
Stable 99
Incubating 31
Deprecated 0
Total 130

Type Wrapping/Unwrapping¶

Include standard library types in union wrapping¶

Includes standard library types as candidates in union wrapping

Property Value
ID include-stdlib-in-union-wrapping
Settings Key includeStdlibInUnionWrapping

Prefer project types in union wrapping¶

Always prioritizes project types over standard library types in union wrapping

Property Value
ID prefer-own-types-in-union-wrapping
Settings Key preferOwnTypesInUnionWrapping

Unwraps collection items to match the expected type annotation

ID unwrap-items-to-expected-type

ID wrap-with-expected-type

🧪 Status: Incubating

Property Value
ID function-to-protocol
Settings Key enableFunctionToProtocolIntention

Convert function to lambda¶

Converts a simple single-expression function into a lambda assignment. Only available for module-level functions with a single return statement and no decorators.

Property Value
ID convert-fn-to-lambda
Settings Key enableConvertFunctionToLambdaIntention

Convert static method to instance method¶

Removes the @staticmethod decorator and adds self as the first parameter, converting the method into a regular instance method

Property Value
ID convert-static-to-instance-method
Settings Key enableConvertStaticMethodToInstanceMethodIntention

Convert static method to instance method — call-site rewrite¶

When converting a @staticmethod to an instance method, inserts TODO comments before class-qualified call sites and co-converts @staticmethod overrides in subclasses

Property Value
ID convert-static-to-instance-method-call-site-rewrite
Settings Key enableConvertStaticMethodCallSiteRewrite

Copy method annotations from parent¶

Copies type annotations from a parent method to its overrides

Property Value
ID copy-method-annotations-from-parent
Settings Key enableCopyMethodAnnotationsFromParentIntention

Property Value
ID dict-access
Settings Key enableDictAccessIntention
