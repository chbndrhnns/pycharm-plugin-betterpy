Search Everywhere¶

The plugin extends the IDE's Search Everywhere (Shift+Shift) functionality.

Pytest Identifier Contributor¶

You can now search for specific pytest node IDs directly from the Search Everywhere dialog. This is particularly useful for finding specific test cases in large, parametrized test suites.

Simply start typing part of a test name or a parameter value, and the plugin will suggest matching pytest nodes.
