A few things to know

Before you install.

Designed to fit the way you already work.

What does BetterPy add to PyCharm?

BetterPy adds Python intentions, inspections, refactorings, navigation, and pytest tools. They appear in familiar IDE surfaces such as context actions, the editor, and the structure view.

Is BetterPy free?

Yes. BetterPy is free.

Which PyCharm versions are supported?

BetterPy maintains releases for PyCharm 2026.1, 2026.2, and 2026.3. Check the Marketplace listing for the exact build compatible with your IDE.

Can I turn individual features off?

Yes. Open Settings → Tools → BetterPy and enable only the features you want. You can also disable or uninstall the plugin through PyCharm’s Plugins settings.

Where do I find BetterPy actions?

Place the caret on the code you want to change and open PyCharm’s context actions menu. Available actions depend on the code and your enabled features.

Does BetterPy collect my code?

BetterPy’s anonymous usage analytics do not collect source code, file paths, or project names. Analytics follow the IDE usage statistics preference initially and can be changed in BetterPy’s Analytics & Privacy settings. Read the privacy information.

Where can I report an issue?

Use Create GitHub Issue from the BetterPy status bar menu to include diagnostics, or visit the issue tracker. Review diagnostic data before sharing it.
