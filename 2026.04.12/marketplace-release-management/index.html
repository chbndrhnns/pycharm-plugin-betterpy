Marketplace Release Management¶

This guide covers how to manage BetterPy releases on the JetBrains Marketplace using the Marketplace REST API.

Prerequisites¶

  • A Marketplace API token (permanent token). Generate one at: https://plugins.jetbrains.com/author/me/tokens
  • The plugin numeric ID. BetterPy's ID is 29896.

Tip: You can look up the numeric ID from the XML plugin ID: 

curl -s "https://plugins.jetbrains.com/api/plugins?family=intellij&xmlId=com.github.chbndrhnns.betterpy" \
  | python3 -m json.tool | grep '"id"'

Common Operations¶

All examples below use the environment variable $MP_TOKEN for the API token:

export MP_TOKEN="perm:your-token-here"

List All Published Versions¶

curl -s \
  -H "Authorization: Bearer $MP_TOKEN" \
  "https://plugins.jetbrains.com/api/plugins/29896/updates" \
  | python3 -c "
import json, sys
for u in json.load(sys.stdin):
    ch = u.get('channel') or '(stable)'
    print(f\"id={u['id']}  version={u['version']}  channel={ch}\")
"

Each update has a numeric id (the update ID) which is needed for deletion.

Delete a Specific Version¶

Use the update ID (not the version string) to delete a release:

curl -s -w "\nHTTP %{http_code}\n" \
  -X DELETE \
  -H "Authorization: Bearer $MP_TOKEN" \
  "https://plugins.jetbrains.com/api/updates/{updateId}"

Replace {updateId} with the numeric ID from the list command above.

A successful deletion returns HTTP 200 and the message "Update has been removed".

Delete Multiple Versions¶

To delete several versions at once, first list them to get the update IDs, then loop:

for id in 1234 1235 1236; do
  echo "Deleting update $id..."
  curl -s -w " HTTP_CODE:%{http_code}\n" \
    -X DELETE \
    -H "Authorization: Bearer $MP_TOKEN" \
    "https://plugins.jetbrains.com/api/updates/$id"
done

Upload a New Version¶

Upload to the Stable channel (omit the channel field):

curl -i \
  -H "Authorization: Bearer $MP_TOKEN" \
  -F "pluginId=29896" \
  -F "file=@/path/to/plugin.zip" \
  "https://plugins.jetbrains.com/plugin/uploadPlugin"

Upload to a pre-release channel (beta, alpha, dev, etc.):

curl -i \
  -H "Authorization: Bearer $MP_TOKEN" \
  -F "pluginId=29896" \
  -F "file=@/path/to/plugin.zip" \
  -F "channel=beta" \
  "https://plugins.jetbrains.com/plugin/uploadPlugin"

Important — channel=default is NOT Stable. On the JetBrains Marketplace, the Stable channel is represented by an empty channel value. To publish to Stable, omit the channel form field entirely (or pass an empty string). Passing channel=default creates/uses a custom channel literally named default, which is separate from Stable and will not be shown as the default download.

You can verify via the list endpoint: Stable updates return an empty channel field (""), while custom channels return their literal name.

See VERSIONING.md for channel conventions.

API Endpoints Reference¶

Operation Method Endpoint
Plugin info (by XML ID) GET /api/plugins?family=intellij&xmlId={xmlId}
List updates GET /api/plugins/{pluginId}/updates
Delete an update DELETE /api/updates/{updateId}
Upload plugin POST /plugin/uploadPlugin

Base URL: https://plugins.jetbrains.com

Important Notes¶

  • Deletion is permanent. There is no undo. Always verify the update IDs before deleting.
  • Authentication: All mutating operations require the Authorization: Bearer header with a valid permanent token.
  • Rate limiting: The Marketplace API may rate-limit requests. Add a short delay between bulk operations if needed.
  • The upload endpoint is documented in detail at: Plugin Upload API
