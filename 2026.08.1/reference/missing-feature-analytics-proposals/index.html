Missing Feature Analytics Proposals¶

This document lists non-internal feature declarations that currently have no feature-level analytics event path. The gap was identified by comparing src/main/resources/META-INF/features/*.xml feature IDs with FeatureAnalytics.FeatureId. Proposed properties intentionally avoid symbol names, file paths, node IDs, import paths, or other user-authored strings; use counts, booleans, bounded enum values, and sanitized lengths.

Event Shape¶

All proposed events should use the existing feature_used envelope through FeatureAnalytics.record(...) or FeatureAnalytics.recordOncePerSession(...).
